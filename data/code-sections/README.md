# Code sections

Each `.txt` file here is one section of the Livingston Township Code, copied **by hand**
from https://ecode360.com/LI1238 (no scraping).

To add a section, just add a new `.txt` file with this header:

```
section: 170-91
title: Fences
url: <exact eCode360 link to this section>
last_checked: 2026-11-07
keywords: fence, fences, wall, privacy     <- optional, helps search
---
<pasted text>
```

Files that still say `PASTE THE REAL TEXT HERE` are ignored by the AI, so it will never
"answer" from an empty placeholder.
